# 青禾账本 0.2.0

## 退款简化

退款已直接冲减发生月净支出，原单关联变为可选。已知分类直接抵扣对应分类，不明确的暂列未分类，可在“退款分类”或流水中批量调整。退款超过当月支出时允许显示负净支出。

## 基金与存款

1. 在“我的账户”添加基金账户（每只基金独立命名），或小荷包等存款账户。
2. 打开一笔流水详情，在“资金用途与归属”选择买入、赎回或存取，再选目标账户；也可批量选择流水后统一指定。
3. 勾选记住商户，或在设置中创建商户与商品关键词规则。需要整理历史流水时勾选同时应用已有记录，已关联的记录保留原样。

资金划转不计日常支出，原付款账户与原始凭据保留。基金净投入不是实时市值。

## 升级

退出旧版后启动本目录的程序。原账本从本机用户数据目录直接读取，不需要重新导入。保存后账本结构升级为版本2，旧版本不能继续写入新版账本。

本次按用户要求仅构建，不运行测试或打开界面检查。
